ベール製造計画（Python版キット）

【初回のみ】
 1. Python 3.12 をインストール（同梱の python-3.12.10-amd64.exe）
    ・最初の画面で「Add python.exe to PATH」にチェック → 「Install Now」
 2. このフォルダを C:\BalePlanner など分かりやすい場所に置く
 3. setup_env.py をダブルクリック
    → 最後に「セットアップが完了しました。」と出れば完了
    → デスクトップにショートカットが2つできます

【毎回の起動】
 デスクトップの「ベール製造計画」          … 通常の起動
 デスクトップの「ベール製造計画（全画面）」 … タブレット向け（F11で切替）
 ※ショートカットが無い場合は start_app.pyw / start_app_fullscreen.pyw をダブルクリック

【データの保存場所】
 %LOCALAPPDATA%\BalePlanner\bale_planner.db

詳しい手順・困ったときは install_python.md を参照してください。
