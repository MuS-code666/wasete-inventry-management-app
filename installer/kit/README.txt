ベール製造計画（Python版キット）

【初回のみ】
 1. Python 3.12 をインストール（python-3.12.*-amd64.exe。同梱されていればそれを使用）
    ・最初の画面で「Add python.exe to PATH」にチェック → 「Install Now」
 2. このフォルダを C:\BalePlanner など分かりやすい場所に置く
 3. setup_env.bat をダブルクリック → 最後に「SETUP COMPLETED」と出れば完了

【毎回の起動】
 start_app.bat            … 通常の起動
 start_app_fullscreen.bat … タブレット向け全画面（F11で切替）

【データの保存場所】
 %LOCALAPPDATA%\BalePlanner\bale_planner.db

詳しい手順・困ったときは install_python.md を参照してください。
