# Python版の導入手順（インストーラを使わない方法）

ベール製造計画を、Python から直接起動する形で顧客PCに導入する手順です。

**この方法を使う場面**

- 顧客PCで Windows 11 の「スマート アプリ コントロール」が **オン** になっていて、
  インストーラ版（`BalePlanner-Setup-*.exe`）が「アプリ制御ポリシーによってブロックされました」となる場合
- コード署名を用意するまでのつなぎ

Python 本体は Python 公式の署名付きなので、スマート アプリ コントロールが有効でも起動できる見込みが高い方法です
（開発PC＝スマート アプリ コントロール有効 で動作を確認済み。ただし全てのPCでの動作を保証するものではありません）。

---

## 全体の流れ

| 場所 | 作業 | 所要時間の目安 |
| --- | --- | --- |
| 開発PC | ① キット（持っていくファイル一式）を作る | 5分 |
| 顧客PC | ② Python をインストールする | 5分 |
| 顧客PC | ③ キットをコピーして `setup_env.py` を実行する（ショートカットも自動作成） | 3分 |
| 顧客PC | ④ 起動・初期設定 | 10分 |

> **.bat ファイルは使いません。** メールやダウンロードで受け取った .bat は、スマート アプリ コントロールが
> 有効なPCで「インターネットから来た危険な拡張子」としてブロックされ、「実行」ボタンも出ないためです。
> セットアップは Python のスクリプト（`.py`）で行い、起動はショートカット（Python を直接起動）で行います。

顧客PCでの作業に **インターネット接続は不要** です（Python のインストーラをキットに同梱した場合）。
管理者権限も不要です。

---

## ① 開発PCでキットを作る

### 1-1. Python のインストーラを用意する（顧客PCがオフラインの場合）

1. 次の URL から **Python 3.12.10** の Windows インストーラ（64ビット）をダウンロードする
   https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe
   - 3.12 はセキュリティ修正のみの期間に入っており、3.12.11 以降は Windows 用インストーラが提供されていません。
     3.12.10 が Windows インストーラのある最後の 3.12 です（開発環境と同じバージョン）
2. （任意）ファイルを右クリック →「プロパティ」→「デジタル署名」で、署名者が **Python Software Foundation** であることを確認する

> 顧客PCがインターネットにつながる場合は、この手順は省略して顧客PCで直接ダウンロードしても構いません。

### 1-2. キットを作成する

プロジェクトのフォルダで PowerShell を開き、次を実行します（`-PythonInstaller` は 1-1 のファイル）。

```powershell
powershell -ExecutionPolicy Bypass -File installer\make_python_kit.ps1 -PythonInstaller C:\Users\<ユーザー名>\Downloads\python-3.12.10-amd64.exe
```

テストを実行したうえで、次の2つが作られます。

```
dist\BalePlanner-PythonKit-<バージョン>\      … キット本体
dist\BalePlanner-PythonKit-<バージョン>.zip   … 上を ZIP にしたもの（持ち運び用）
```

キットの中身:

| ファイル・フォルダ | 内容 |
| --- | --- |
| `bale_planner\` | アプリ本体 |
| `wheels\` | オフラインで入れるための追加パッケージ（jpholiday） |
| `requirements.txt` | 必要なパッケージの一覧 |
| `setup_env.py` | 顧客PCでの初回セットアップ（ダブルクリック）。デスクトップにショートカットも作る |
| `start_app.pyw` | 通常の起動（ショートカットが使えない場合の予備） |
| `start_app_fullscreen.pyw` | タブレット向け全画面の起動（同上） |
| `README.txt` | 手順の要約 |
| `install_python.md` | この手順書 |
| `python-3.12.*-amd64.exe` | Python のインストーラ（同梱した場合） |

ZIP を USB メモリなどで顧客PCに持っていきます。

## ② 顧客PCに Python をインストールする

> すでに Python 3.11 以降が入っている場合は省略できます。
> 確認方法: コマンドプロンプトで `py --version` と入力し、`Python 3.11` 以上が表示されれば OK。

1. `python-3.12.*-amd64.exe` をダブルクリックする
2. 最初の画面の下にある **「Add python.exe to PATH」にチェック** を入れる
   （「Use admin privileges when installing py.exe」は、管理者権限がなければチェックを外す）
3. **「Install Now」** を押す
4. 「Setup was successful」と表示されたら **Close** を押す

> 「Install Now」の標準設定には、画面表示に必要な tcl/tk が含まれています。
> 「Customize installation」を選んだ場合は、**「tcl/tk and IDLE」のチェックを外さない** でください。

---

## ③ キットをコピーしてセットアップする

1. ZIP を右クリック →「すべて展開」で展開する
2. 展開したフォルダを **分かりやすい場所に置く**（例: `C:\BalePlanner`）
   - デスクトップや「ダウンロード」フォルダのままでも動きますが、誤って削除しないよう専用の場所を推奨します
   - 置き場所は後から動かさないでください（動かした場合は `setup_env.py` をもう一度実行）
3. フォルダ内の **`setup_env.py` をダブルクリック** する
   - 「このファイルを開く方法を選んでください」と出た場合は、Python（ロケットのアイコン）を選ぶ
4. 黒い画面に次のように表示され、最後に **「セットアップが完了しました。」** と出れば完了です。Enter キーで閉じます。

```

[4/5] 動作確認をしています...
      version: 0.1.0

 セットアップが完了しました。

```

「エラー:」と表示された場合は、後述の「困ったときは」を参照してください。

## ④ 起動・初期設定

### 起動

デスクトップにできたショートカットから起動します。

- **ベール製造計画** … 通常の起動
- **ベール製造計画（全画面）** … タブレット向けの全画面（F11 で切り替え）

使わないほうのショートカットは削除して構いません。

### ショートカットを手動で作る（自動作成できなかった場合）

1. デスクトップの何もない所を右クリック →「新規作成」→「ショートカット」
2. 「項目の場所」に次を入力して「次へ」（`C:\BalePlanner` は実際の置き場所に読み替え。全画面にするなら末尾に ` --fullscreen` を追加）
   ```
   C:\BalePlanner\.venv\Scripts\pythonw.exe -m bale_planner.app
   ```
3. 名前を「ベール製造計画」にして「完了」
4. 作ったショートカットを右クリック →「プロパティ」→「作業フォルダー」に `C:\BalePlanner` を入力 →「OK」
5. （任意）同じ画面の「アイコンの変更」→「参照」で `bale_planner\assets\app.ico` を選ぶ

> ショートカットの代わりに、フォルダ内の `start_app.pyw`（全画面は `start_app_fullscreen.pyw`）をダブルクリックしても起動できます。

### 初期設定（初回のみ）

1. 「設定」画面で、保管上限・製造能力・稼働時間・運搬業者を現場の値に変更する
2. 「今日」画面の「実在庫を入力」から、現在の在庫を登録する
3. 「出荷予定」画面で出荷予定を登録する

## データの保存場所とバックアップ

入力したデータは、アプリのフォルダではなく次の場所に保存されます（インストーラ版と共通）。

```
%LOCALAPPDATA%\BalePlanner\bale_planner.db
```

- エクスプローラーのアドレス欄に `%LOCALAPPDATA%\BalePlanner` と入力すると開けます
- アプリを終了した状態でこのファイルをコピーすればバックアップになります
- アプリのフォルダを入れ替えても、データはそのまま引き継がれます

---

## アップデート（新しいバージョンにする）

1. アプリを終了する
2. 新しいキットを展開し、**古いフォルダと入れ替える**（同じ場所に置く）
3. 新しいフォルダで `setup_env.py` を実行する（ショートカットも作り直されます）

データ（`%LOCALAPPDATA%\BalePlanner`）は消えません。

## 削除する

1. アプリのフォルダ（例: `C:\BalePlanner`）とデスクトップのショートカットを削除する
2. データも消す場合は `%LOCALAPPDATA%\BalePlanner` フォルダを削除する
3. Python が不要になった場合は「設定」→「アプリ」から「Python 3.12」をアンインストールする

## 困ったときは

| 表示・症状 | 原因と対処 |
| --- | --- |
| `.bat` を開くと「Windows によって PC が保護されました」で「実行」ボタンが無い | 古いキット（.bat 版）を使っている。新しいキット（`setup_env.py` が入っているもの）を使う |
| `setup_env.py` をダブルクリックするとメモ帳などで開く／何も起きない | Python が入っていない、または .py が Python に関連付けられていない。② の手順で Python を入れる。それでも開けない場合は下の「コマンドで実行する」 |
| 「エラー: Python 3.11 以降が必要です」 | 古い Python が使われている。② の手順で Python 3.12 を入れてから `setup_env.py` を再実行 |
| 「エラー: この Python には画面表示の部品（tcl/tk）がありません」 | Python のインストーラを再実行 →「Modify」→「tcl/tk and IDLE」にチェック → 完了後に `setup_env.py` を再実行 |
| 「コマンドが失敗しました」で `No matching distribution` など | `wheels` フォルダが無い・中身が空。キットを作り直すか、`wheels` フォルダごとコピーし直す |
| ショートカットを押しても何も起きない | フォルダを移動した、または `setup_env.py` が途中で失敗した。`setup_env.py` を実行し直す |
| `py --version` で Microsoft Store が開く | Windows 標準の「アプリ実行エイリアス」が反応している。② の手順で python.org の Python を入れれば解消する |
| 「アプリ制御ポリシーによってブロックされました」（.py や Python 自体） | 通常は起きない。どのファイルが止められたかを控えて開発担当に連絡する |
| 画面の文字が小さい／大きい | Windows の「設定」→「ディスプレイ」→「拡大/縮小」で調整する |

原因が分からない場合は、`setup_env.py` の黒い画面の写真（または同じフォルダにできる `setup_check.txt`）を開発担当に送ってください。

### コマンドで実行する（setup_env.py が開けない場合）

スタートメニューで「cmd」と入力して「コマンド プロンプト」を開き、1行ずつ入力して Enter を押します
（`C:\BalePlanner` は実際の置き場所に読み替え）。手入力のコマンドはブロックされません。

```
cd /d C:\BalePlanner
py -3 -m venv .venv
.venv\Scripts\python -m pip install --no-index --find-links wheels -r requirements.txt
.venv\Scripts\python -m bale_planner.app --check setup_check.txt
type setup_check.txt
```

最後に `RESULT: OK` と出ればセットアップ完了です。続けて「ショートカットを手動で作る」の手順でショートカットを作ります。
