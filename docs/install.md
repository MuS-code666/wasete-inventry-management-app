# インストール手順（ベール製造計画）

## 動作環境

- Windows 10 / 11（64ビット）
- Python などの追加ソフトは不要（インストーラにすべて含まれています）
- インターネット接続は不要
- 管理者権限は不要（管理者として実行すると「すべてのユーザー」向けのインストールも選べます）

## インストール

1. `BalePlanner-Setup-<バージョン>.exe` をUSBメモリなどで対象のPCにコピーし、ダブルクリックします。
2. 青い画面「Windows によって PC が保護されました」が出た場合は、**詳細情報** → **実行** を押します。
   （署名のないアプリをインターネットから入手した場合に表示されます）
3. 画面の案内に従って「次へ」を押します。必要なら「デスクトップ上にアイコンを作成する」にチェックします。
4. 完了するとスタートメニューに次の2つが登録されます。
   - **ベール製造計画** … 通常の起動
   - **ベール製造計画（全画面）** … タブレット向けの全画面起動（F11 で切り替え）

初回起動時は「実在庫がまだ入力されていません」と表示されます。「実在庫を入力」から現在の在庫を登録してください。
運搬業者・保管上限などは「設定」画面で現場の値に変更してください。

## スマートアプリコントロールについて（重要）

Windows 11 の **スマートアプリコントロール** がオンになっているPCでは、署名のないアプリが
起動・アンインストールできないことがあります（「アプリ制御ポリシーによってブロックされました」と表示されます）。

- 確認方法: 「Windows セキュリティ」→「アプリとブラウザー コントロール」→「スマート アプリ コントロールの設定」
- 「オフ」または「評価」なら問題ありません。
- 「オン」の場合の対策:
  - **推奨:** アプリにコード署名をしてから配布する（開発側の対応。コード署名証明書が必要です）
  - **当面の代替:** インストーラを使わず Python から起動する方法で導入する → [install_python.md](install_python.md)
  - スマートアプリコントロールをオフにする方法もありますが、Windows のバージョンによっては一度オフにすると
    再インストールしないとオンに戻せないため、PCの管理者と相談のうえ判断してください。

## データの保存場所とバックアップ

入力したデータ（在庫・出荷予定・設定）は次のファイルに保存されます。

```
%LOCALAPPDATA%\BalePlanner\bale_planner.db
```

エクスプローラーのアドレス欄に `%LOCALAPPDATA%\BalePlanner` と入力すると開けます。
アプリを終了した状態でこのファイルをコピーすればバックアップになります。

## アップデート

新しいバージョンのインストーラをそのまま実行してください。入力済みのデータは引き継がれます。

## アンインストール

「設定」→「アプリ」→「インストールされているアプリ」→「ベール製造計画」→「アンインストール」。
入力したデータは削除されずに残ります。不要な場合は `%LOCALAPPDATA%\BalePlanner` フォルダを手動で削除してください。

## インストーラの作り方（開発者向け）

開発PCで次を実行すると `dist\BalePlanner-Setup-<バージョン>.exe` ができます。

```
build_installer.bat
```

事前準備（初回のみ）:

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
winget install JRSoftware.InnoSetup --scope user
```

バージョン番号は `bale_planner/__init__.py` の `__version__` で管理します。
ビルドスクリプトは、テスト → exe 作成 → exe の動作確認（`--check`）→ インストーラ作成 の順に実行し、
途中で失敗した場合はインストーラを作りません。
