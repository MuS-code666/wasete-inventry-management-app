# ベール在庫・製造・出荷計画アプリ 仕様（試作版）

## 1. 目的

工場で製造するベールについて、現在庫・出荷予定・製造能力をもとに、日々の製造数と圧縮梱包機の運転時間を提案する。
今後2週間の出荷予定を踏まえて製造計画を立て、現場で計画を変更したときにも対応できるようにする。

## 2. 基本マスタ（設定画面で変更できる）

| 項目 | 初期値 | 備考 |
| --- | --- | --- |
| 保管上限 | 130 ベール | 出荷待ちのベールを含む。**仮の値** |
| 標準製造能力 | 12 ベール/時 | **仮の値** |
| 午前の実質稼働時間 | 190 分 | 8:30〜12:00、休憩20分 |
| 午後の実質稼働時間 | 220 分 | 13:00〜17:00、休憩20分 |
| 残業上限 | 60 分/日 | 製造日の午後（17:00以降）にだけ追加する。**仮の値** |
| 休日出勤 | 有効 | 休業日に午前190分・午後220分まで製造できる |
| 期間末目標在庫 | 60 ベール | 在庫最大化モードだけで使う。**仮の値** |
| 計画期間 | 14 日 | |
| 製造可能日 | 月〜土 | 休業日を除く |
| 出荷可能日 | 月〜金 | 休業日を除く。臨時稼働日は曜日に関係なく出荷できる |
| 休業日 | 日曜、第2土曜（月の2回目の土曜）、祝日（jpholiday で判定）、臨時休業日 | |

## 3. 計算ルール（確定事項）

### 3.1 在庫の動き

1日を午前と午後の2つの時間帯に分け、在庫は次の順に動くものとする。

```
始業在庫 → 午前出荷(−) → 午前製造(+) → 午前終了時在庫 → 午後出荷(−) → 午後製造(+) → 終業在庫
```

- 保管上限は、午前終了時と終業時の2回チェックする。

### 3.2 出荷期限

- 午前出荷：前の製造日の終業時までに製造が終わっていること。月曜の午前出荷は土曜に製造した分で間に合う。
- 午後出荷：当日の午前中までに製造が終わっていること。
- 休業日をはさむ場合は、さらに前の製造日が期限になる。
- 実装上は、上の3つを「出荷する時間帯より前の時間帯で製造した分だけを出荷できる」という1つのルールで扱っている。

### 3.3 製造能力

- 運転時間は分単位で提案する。立ち上げ・片付けの時間は運転時間に含めない。
- 製造数は整数で、端数は切り捨てる。例：190分 × 12ベール/時 ÷ 60 = 38ベール。
- 製造枠は、通常稼働 → 残業 → 休日出勤 の順に優先して使う。足りないときは、計画の中で自動的に残業や休日出勤を使う。

### 3.4 モード

| モード | 考え方 |
| --- | --- |
| 在庫最小化 | 出荷期限に間に合う範囲で、製造をできるだけ後ろ倒しにする。期限から逆算して割り当てる |
| 在庫最大化 | 保管上限を守りながら、通常稼働時間内でできるだけ前倒しで製造する。期間末に目標在庫になるよう製造総数を調整する。在庫最小化モードで計算した累計製造数を常に下回らないため、出荷期限は必ず守られる |

### 3.5 実在庫の入力と起点

- 現場で確認した実在庫の数値を優先する。
- 最も新しい入力を計画の起点にする。同じ日に始業時と終業時の両方が入力された場合は、終業時を優先する。
- 終業時の入力を起点にした場合は、翌日から計画する。
- この方式なら、始業時と終業時の両方を数えてしまう二重計上は起きない。

### 3.6 手動変更

- 作業員が変更した製造数は「確定値」として固定する。確定値以外の時間帯は、すべて自動で再計算する。

### 3.7 警告と対策の提案

| 警告 | 提案する対策 |
| --- | --- |
| 出荷不足 | 出荷を後の時間帯へ変更する／業者ごとに減らすトラック台数／残業上限の延長（必要な分数）／休日出勤を有効にする |
| 保管上限超過（連続する期間は1件にまとめる） | 一部を前倒しで出荷する、または複数便に分割する／保管上限を見直す／確定値を減らす |
| 手動確定値が製造可能数を超えている | 製造数を見直す |
| 出荷できない日に出荷予定がある | 出荷日を変更する／臨時稼働日として登録する |
| 期間末に目標在庫へ届かない（お知らせ） | 目標在庫を見直す |
| 残業・休日出勤を使った（お知らせ） | 時刻・分数を表示する |

- 原料の制約は、試作版では考慮しない。

## 4. 試作の構成

| ファイル | 役割 |
| --- | --- |
| `bale_planner/models.py` | マスタ・入力・計画結果のデータ構造 |
| `bale_planner/workcalendar.py` | 製造可能日・出荷可能日の判定 |

| `bale_planner/cli.py` | コンソール表示・CSV出力 |
| `tests/` | pytest によるテスト |

### テストシナリオ

| キー | 内容 | 確認したいこと |
| --- | --- | --- |
| normal | 通常の2週間（11/23 祝日を含む） | 基本の動作 |
| monday_big | 月曜午前に126ベールの出荷 | 土曜の製造分で間に合うか |
| holiday | 臨時休業日と臨時稼働日（日曜）がある | カレンダーの上書き |
| tight_storage | 1便で132ベール（保管上限130を超える） | 保管上限超過の警告 |
| overtime | 翌朝88ベールの出荷、在庫0 | 残業を自動で使うか |
| holiday_work | 祝日明けの火曜午前に126ベールの出荷 | 残業 → 休日出勤の順に使うか |
| shortage | 翌朝128ベールの出荷、在庫0 | 出荷不足の警告と対策の提案 |
